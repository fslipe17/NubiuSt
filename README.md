# NubiSt - Software de Armazenamento em Nuvem

Nesse Repositório estou desenvolvendo o NubiSt, um software de armazenamento em nuvem desenvolvido para permitir o armazenamento, organização e gerenciamento de arquivos de forma prática e acessível.

O projeto está em desenvolvimento e tem como objetivo criar uma plataforma de armazenamento em nuvem utilizando HTML, CSS e JavaScript.

Este projeto está sendo desenvolvido por fslipe17.

# Tecnologias Utilizadas
1.HTML
2.CSS
3.JavaScript
Status do Projeto
